Fixed: Every record type now reads one name on all of its screens. A record's
noun used to be written out at each place that said it, so one record carried
several spellings. The result count on the Biocontrol list said releases where
the record's own pages said biocontrol action; Outreach counted actions;
Weather counted stations; Chemical counted applications under headings saying
chemical application; Source Reduction and Habitats counted source reductions
while the habitat page said the same; and Requests for Control and Service
Requests both counted plain requests, which was one word for two different
records on two lists people move between. Those counts now say the record's own
name. The delete card and the unavailable state on Requests for Control also
read Request for Control rather than Request For Control.
