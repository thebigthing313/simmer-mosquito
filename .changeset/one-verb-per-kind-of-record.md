Changed: a create surface is named with one verb per kind of record, in its
sidebar entry, its page title, its explorer header control and the map's
right-click menu alike. `Record` is work performed: Inspection, Collection,
Chemical Application, Biocontrol Action, Source Reduction, Outreach Action.
`Create` is a thing brought into existence: Habitat, Trap, Address, Region,
Contact, Mission, Assignment, Request for Control, Service Request, Weather
Station. `Add` is a child under a parent that already exists. `New` is gone.
So the sidebar's `Create Inspection` reads `Record Inspection`, `Add Trap` and
`Add Weather Station` read `Create Trap` and `Create Weather Station`, and
`New Service Request`, `New Contact`, `New Request for Control`, `New
Assignment` and `New Mission` all read `Create`. The trap explorer's `Add Trap`
and the weather explorer's `Add Station` follow, and the map menu's `New
Habitat` and the rest read the same words as the sidebar entry they open. The
Manage Routes page's `New Route` reads `Create Route`, and the region folder
dialog's `New Region Folder` and `New Folder` read `Create`.

Changed: every create and edit form's submit button reads `Save`. The create
forms had been saying `Create Habitat`, `Record Collection`, `Add Station` and
`Raise Request`, and the edit forms `Save Changes` or `Save changes`, so the
same act had eighteen names. The entry or title says what the form makes; the
button says the act of keeping it.
