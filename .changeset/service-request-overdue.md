Added: an open service request older than your Organization's overdue threshold, 14 days unless an Admin changes it under My Organization, Public Engagement, is marked overdue. Its age shows in the warning colour on the Service Requests map and in the Table, both can narrow to overdue requests with the Overdue filter, and Operations Backlog on the Dashboard counts them with the oldest one's age, linking to the map with the filter on. An Admin can set any whole number of days up to 365 or turn the threshold off, which takes all three away.
